# 板级驱动（BSP）

| 子目录 | 作用 | 当前状态 |
| --- | --- | --- |
| `IIC/` | 软件 IIC 起停、收发和寄存器读写 | 当前 MPU6050 链路使用；SCL/PB6、SDA/PB7 以 `iic.h` 为准 |
| `MPU6050/` | WHO_AM_I、初始化、原始加速度读取和 `g` 值换算 | 当前采样链路使用；加速度量程为 ±2 g |
| `KEY/` | 按键驱动 | 板级预留模块 |
| `LED/` | LED 驱动 | 板级预留模块 |
| `LCD/` | LCD 显示和控制器初始化 | 板级预留模块 |

传感器安装和实验轴向由数据契约限定：X 是振动测量轴、Y 是重力参考轴。不要把传感器异常的单轴读数通过改名或 CSV 元数据伪装为 X 轴；应先根据 [MPU6050 Z 轴异常记录](../../../06_笔记与踩坑/开发问题/Q-02_MPU6050_Z轴异常.md) 排查。

IIC 引脚与其他外设不能复用。该限制来自已记录的总线冲突问题，具体证据见 [IIC 三轴整值错乱记录](../../../06_笔记与踩坑/开发问题/Q-04_IIC三轴整值错乱.md)。
