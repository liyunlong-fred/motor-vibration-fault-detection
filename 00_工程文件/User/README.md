# 固件入口与中断配置

| 文件 | 责任 |
| --- | --- |
| `main.c` | 初始化 HAL、时钟、USART、MPU6050、采样、FFT 和帧链路，并在主循环中调度窗口处理 |
| `stm32f4xx_it.c/.h` | Cortex-M 异常与外设中断处理；TIM3 采样中断由应用层回调处理 |
| `stm32f4xx_hal_conf.h` | 本工程启用的 HAL 模块和相关配置 |

采样频率、窗口和调试模式不在本目录硬编码，应通过 `../APP/app_config.h` 调整。不要在中断里加入耗时的 FFT、串口整帧发送或阻塞操作；窗口处理由主循环与 `APP/` 层分工完成。
