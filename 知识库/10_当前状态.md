## 核实基线

- 核实日期：2026-09-27。
- 本次核实使用的主线基线：`bb64fdf`；本次知识库更新将在该基线上形成新的主线提交。
- 已验证的采样时序测试在远程 `timing-test` 分支完成，使用提交 `4957096` 和 `75ce768`；临时计时打点未合并到主线。
- 固件当前参数：1 kHz 采样、1024 点窗口、真实 MPU6050 数据源、USART1 460800 baud。
- MPU6050：软件 IIC 使用 PB6/PB7，加速度量程为 ±2 g。
- 数据口径：测量轴 X、Y 为静态安装重力参考轴并记录正负号；三类为正常 / 不平衡 / 安装固定处机械松动。schema v4 已在 Python 配置和元数据模块中实现：正式采集强制记录夹具、传感器、测点、安装姿态、标定与固件构建；文件头仅保存不可变采集事实，质检、划分和文件 SHA-256 以 manifest 为准。轴承异常已退出项目范围。
- Python 环境：项目根目录 `.conda/` 已统一为 Python 3.13.13；依赖版本记录在根目录 `requirements.txt`，VS Code 默认解释器指向 `${workspaceFolder}\\.conda\\python.exe`。

## 当前主要风险

- 现有历史频谱没有与本次 TACH 记录同步采集；在电压标签和同工况对拍完成前，不能继续沿用“36.6 Hz 是 1×、73.2 Hz 是 2×”的旧解释。截图工况若与该频谱相同，则 PPR=2 会指向相反结论：73.2 Hz 附近更可能是 1×。
- 七叶片 BPF 在截图工况和 12 V 工况分别约 508.64 Hz、642.20 Hz，超过 1 kHz 采样的 500 Hz 奈奎斯特频率，存在前端衰减或混叠风险，不能直接用带内峰反推叶频。
- 机械松动尚无重复性数据；若夹具、紧固点或回退圈数记录不一致，模型可能只学到台面耦合差异。
