# 当前状态

> 本页是项目进度的唯一当前摘要。详细证据仍以链接到的源码、配置、数据和历史记录为准。

## 核实基线

- 核实日期：2026-09-27。
- 本次核实使用的主线基线：`bb64fdf`；本次知识库更新将在该基线上形成新的主线提交。
- 已验证的采样时序测试在远程 `timing-test` 分支完成，使用提交 `4957096` 和 `75ce768`；临时计时打点未合并到主线。
- 固件当前参数：1 kHz 采样、1024 点窗口、真实 MPU6050 数据源、USART1 460800 baud。
- MPU6050：软件 IIC 使用 PB6/PB7，加速度量程为 ±2 g。
- 数据口径：测量轴 X、重力轴 Y；三类为正常 / 不平衡 / 安装固定处机械松动，schema v3 已在 Python 配置和元数据模块中实现。轴承异常已退出项目范围。
- Python 环境：项目根目录 `.conda/` 已统一为 Python 3.13.13；依赖版本记录在根目录 `requirements.txt`，VS Code 默认解释器指向 `${workspaceFolder}\\.conda\\python.exe`。

## 已完成并有证据

- STM32 定时采样、1024 点双缓冲、串口数据帧和文本日志帧已实现。
- 板上完成去均值、Hann 窗、CMSIS-DSP 实数 FFT 和 10～400 Hz TOP-5 峰值输出。
- 历史对拍中，同一窗口的板上与 PC 端 bin、频率和幅值一致；操作与验证口径见 [D4 板上 FFT 集成与对拍记录](../01_文档/技术实施/历史验证/D4_板上FFT集成与对拍记录.md)，原始输出保存在 `05_演示与输出/boardlog/`。
- Python 侧已有接收、频谱、峰值、谐波、原始数据检查和数据集清单工具。
- schema v3 标签契约、松动量化字段、元数据读写和数据集清单生成代码已落地；2026-09-24 本地 `test_metadata.py` 已验证默认映射、缺失量化值拦截、完整松动记录、元数据往返和 manifest 写入。
- 面向非开发人员的数据采集操作手册已建立，覆盖 PowerShell 环境准备、debug/formal 切换、各类工况命令、采集后检查和训练集划分。
- 2026-09-26 完成 1024 点窗口采样时序验证：窗口内 `span=1023`、`miss=0`、`readfail=0`，6 帧串口接收 `lost_frames=0`；但窗口之间仍有约 51～52 ms 暂停，详见 [Q-06 采样时序验证](../06_笔记与踩坑/开发问题/Q-06_1024点窗口采样时序验证.md)。

## 当前主要风险

- 现有“不平衡”样本以 2× 分量为主，物理解释尚未由独立测速完全闭环。
- 机械松动尚无重复性数据；若夹具、紧固点或回退圈数记录不一致，模型可能只学到台面耦合差异。
- 历史 `HANDOFF.md` 当前不在工作树中；若后续恢复，只能作为 2026-09-22 快照，不得替代本页当前状态。
- 规划文档中少量目录名、指标表述和当前实现仍可能不一致，不能直接当运行事实。
