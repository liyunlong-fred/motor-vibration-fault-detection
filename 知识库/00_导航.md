# 项目知识库导航

这里是 Obsidian 与 Codex 共用的项目入口。知识库负责导航和说明信息的权威范围，不复制源码、数据或历史正文。

## 先看哪里

- [当前状态](10_当前状态.md)：已完成、未完成、下一步与风险。
- [系统地图](20_系统地图.md)：从 MPU6050 到 STM32、串口、Python 和数据集的完整链路。
- [决策索引](30_决策索引.md)：已经确定的技术选择及其依据。
- [问题与实验索引](40_问题与实验索引.md)：Q-01～Q-04、FFT 对拍和待完成实验。
- [数据采集操作手册](../04_数据集/采集操作手册.md)：调试、正式采集、质检和训练清单生成步骤。
- [项目规划](../01_文档/项目规划/README.md)：目标、设计方案和长期路线；今后在拆分页维护。
- [技术实施文档](../01_文档/技术实施/README.md)：包含当前的硬件验证方法和可追溯的历史验证记录。
- [D4 板上 FFT 集成与对拍记录](../01_文档/技术实施/历史验证/D4_板上FFT集成与对拍记录.md)：用于追溯 2026-09-22 前后的板上 FFT 实验过程。
- [文档与模块索引](索引/文档与模块索引.md)：由脚本生成的可检索目录。

## 使用原则

1. 当前代码行为以源码、配置和测试为准。
2. 数据集事实以 `manifest.csv` 与实际文件为准。
3. 规划描述目标，交接文档描述历史快照，不能替代当前状态。
4. 只有经过日志、测试、数据或源码核实的事项才能标记为完成。
