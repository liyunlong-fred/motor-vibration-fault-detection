# 系统地图

## 数据流

```text
MPU6050
  │ 传感器内部 FIFO：1 kHz、仅三轴加速度（6 B/样本）
  ▼
app_sample.c
  │ TIM3 服务提示、FIFO 批量取样、三槽连续窗口队列，X 为测量轴
  ├──────────────► link_frame.c ── USART1 TX DMA 队列 ──► recv.py
  │                                                   ├─ debug_raw / raw
  ▼                                                   └─ formal + manifest.csv
dsp_fft.c
  │ 去均值 + Hann + 1024 点 RFFT
  └─ 10～400 Hz TOP-5 ── 文本日志帧 ────────────────► boardlog
```

## 固件边界

| 模块 | 责任 | 主要入口 |
|---|---|---|
| `app_config.h` | 采样率、窗口、数据源、串口等统一参数 | `APP_FS_HZ`、`APP_FRAME_N`、`APP_UART_BAUD` |
| `app_sample.c` | TIM3 服务提示、FIFO/桩数据、三槽连续窗口管理与连续性统计 | `app_sample_init/task/get/release/stats_get` |
| `dsp_fft.c` | 窗函数、RFFT、单边幅值和找峰 | `dsp_fft_init/run/print/selftest` |
| `link_frame.c` | 数据帧和文本日志帧封装；加速度帧携带 `first_sample_id` | `link_frame_send`、`link_text_send` |
| [`Drivers/SYSTEM/`](../00_工程文件/Drivers/SYSTEM/README.md) | 时钟、延时与 USART DMA 队列支持 | `delay/`、`sys/`、`usart/` |
| `main.c` | 初始化和主循环调度 | `main` |
| `iic.c`、`mpu6050.c` | 软件 IIC、传感器寄存器与加速度 FIFO 批量读取 | `iic_init`、`mpu6050_init/fifo_read_raw` |

## PC 工具边界

| 模块 | 责任 |
|---|---|
| `recv.py` | 串口接收、DTR/RTS 处理、数据和日志落盘 |
| `py_common/frames.py` | 与固件一致的帧解析 |
| `py_common/metadata.py` | schema v3 元数据、机械松动量化校验、CSV 头和 manifest |
| `plot_check.py` / `peak_check.py` | 波形频谱和板上/PC 对拍 |
| `harmonics.py` | 基频、转速和谐波族分析 |
| `make_dataset.py` | 从通过质检的 formal 样本生成训练清单 |

## 权威来源

- 参数值：`app_config.h`、`mpu6050.h`、`config.json`。
- 帧格式：`link_frame.h` 与 `py_common/frames.py`，修改时必须同步。
- 数据标签：`04_数据集/README.md`、`config.json`、`metadata.py`；当前三类为 `normal / unbalance / looseness`。
- 当前进度：[当前状态](10_当前状态.md)。
