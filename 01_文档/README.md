# 项目文档

本目录存放可阅读、可追溯的项目资料。按资料性质分区，避免把目标规划、已验证的方法、供应商参考包和临时排查笔记混在一起。

| 目录 | 内容 | 使用方式 |
| --- | --- | --- |
| `项目规划/` | 项目范围、方案和后续设计路线 | 说明目标和取舍，不替代当前实现证据 |
| `技术实施/` | 可复现的硬件验证方法和历史实现/对拍记录 | 按文档生命周期区分当前方法与历史快照 |
| `外设信息/` | 项目使用的 MPU6050 寄存器速查表和本地参考资料 | 用于查阅，不把示例工程当作当前固件来源 |

当前实现、风险和下一步以 [知识库/当前状态](../知识库/10_当前状态.md)、源码、配置、测试和数据清单为准。临时排查过程请写入 `06_笔记与踩坑/`，而不是此目录。
