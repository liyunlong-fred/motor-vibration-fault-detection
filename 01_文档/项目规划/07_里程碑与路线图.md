# 里程碑与路线图


## 1. 当前推进顺序

原 12–14 天冲刺计划是历史估算。当前顺序为：重新烧录并板端/PC 对拍 → 确认机械 1× → 六面标定和夹具验证 → 三类正式采集和质检 → 特征、训练、部署、UI、报警。


## 2. 阶段计划

> 依据你的投入（每天 4–6 h，1–2 周）重排。原则：**先打通最小闭环，再补精致度**；每阶段有退出标准，跟不上就按"砍法"收缩范围，**不要拉长时间**。硬件到货前先做 **D0**；到货日 = D1 起点（Python 与例程已在 D0 备好，D1/D2 可合并推进）。

**D0｜到货前等货期（2–3 天，把"不插电也能做"的做完）**

- **P0 必做（≈半天）**：① 官网下载《探索者 STM32F407 开发指南》HAL 例程源码与视频；② Keil Pack Installer 装 **STM32F4xx_DFP** 器件包；③ 用 Keil 打开官方例程（跑马灯/串口/LCD 显示）**编译通过**——不烧录也要先编译，暴露缺包/版本等环境问题；④ 到资料里找是否有现成 **MPU6050/I2C 例程**，有则预习接线与代码结构（到货直接跑）。
- **P1 推荐（≈半天–1 天）**：⑤ 用"合成文件"模拟串口把练习 4 练掉一半——按 相关页面 帧格式写"按帧切块 + 转 int16"解析函数并用测试数据验证（这段代码将来就是 `make_dataset.py` 读文件的核心）；⑥ 在 `03_Python工具` 里搭 tools 骨架（collect.py / make_dataset.py 占位），把帧协议写成注释。
- **P2 有余力（≈1 天）**：⑦ 预习 MPU6050 寄存器关键页（WHO_AM_I=0x68、PWR_MGMT_1、ACCEL_CONFIG、ACCEL_XOUT_H、FIFO/ODR/DLPF）并画出"初始化→读原始值→FIFO 批量读"的寄存器流程；⑧ 预习 LCD 例程如何画大字/色块（D10 UI 用）；⑨ 装 STM32CubeProgrammer、STM32CubeMX 备用（D8–D9 才用）；⑩ 准备实验台：底座（木板/收纳盒）+ 扎带固定风扇框、热熔胶枪与胶棒就位、万用表/杜邦线归类。

**时间不够的砍法（按顺序砍，保主干）**：

1. 砍路线 B（1D-CNN）→ 只做特征 + MLP；
2. 减少电压档和故障等级，但保留正常 / 不平衡 / 机械松动三类；
3. 屏幕只做页 1（状态大字）；
4. 继电器先不用，用板载 LED + BEEP 演示报警；
5. 复杂松动等级只保留 M1 回退 1/4 圈这一档，优先保证重复装拆和恢复基线验证；
6. 风扇 B 的留出设备测试尽量保住；若没完成，只能报告同设备、按会话分组的结果，不能声称跨设备泛化。

> 若之后时间变充裕，可回到慢速版节奏把 1D-CNN、更多松动等级、更多设备和上位机仪表盘补上（见 相关页面 延伸方向）。
