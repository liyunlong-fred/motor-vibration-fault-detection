# 硬件方案、接线与采购


## 1. 当前硬件口径

MPU6050 使用软件 IIC，SCL=PB6、SDA=PB7；不使用硬件 I2C1、DMA 或原文 PB8/PB9 共用总线方案。数据契约为 X 测量轴、Y 重力轴。六面标定、刚性底板和 M1 往返松动验证尚未完成；采购价格和持有状态均只作参考。

### 2.3 传感器安装

- MPU6050 必须与电机/风扇外壳**刚性耦合**：双面胶/手持会严重衰减中高频并引入共振。**重要**：传感器**不永久固定在某台风扇上**——本项目一次只测 1 台，把传感器装在**可移动的"测量夹具"**上，测完一台换下一台；**买 2 个够用（1 主 1 备），不必每台风扇配 1 个**；
- **非永久固定方式（推荐优先）**：①**螺丝拧紧**（推荐）：用 M2/M3 小螺丝把传感器固定在一块铝 L 角码/固定片上，角码再用扎带或自攻小螺丝固定到风扇塑料框（避开叶片、不破坏平衡），换风扇即拆即移；②**G 型夹 / 小台钳夹具**：夹在风扇框上、夹口垫硅胶，一个夹具依次夹每台，最省事也最公平；③**3M VHB 强力双面胶**：粘牢但可撬下移位（对 0–400 Hz 频段衰减可接受）；④**蜡 / 热熔胶**：非真永久，加热或异丙醇可揭，但麻烦。**固定方式不影响功能，重点是"刚性 + 可复现"**；
- **贴装方向**：排针让商家焊成"向上"——模块底面平整贴安装面、杜邦线从上方插（若排针向下，则元件面朝下贴、针脚朝上接线也可用，别让胶盖住芯片丝印以对轴）；
- **轴向约定**：当前数据契约固定为 X 轴振动测量、Y 轴重力参考。传感器安装后须先检查轴向；不得把历史桩信号的 Y 轴约定当作当前采集轴。
- **测量纪律**：所有样本保持同一夹具、同一安装点（靠近轴承/电机壳中心、径向）和同一手法。相对特征可容忍少量差异，但位置一致性仍是复现性的前提；
- 测量方向对准**径向**（垂直转轴），固定点尽量靠近轴承座/电机壳体中心；
- 实验过程保持传感器与线缆不晃动，避免引入伪振动；
- 记录安装方式照片放进 GitHub README（重现性）。

## 3. 硬件接线

### 3.1 接线说明

| 功能               | 器件引脚                 | STM32 引脚（示例）                                       | 说明                                                                                                               |
| ---------------- | -------------------- | -------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| IIC 时钟（软件模拟） | MPU6050 SCL | **PB6** | 不使用硬件 I2C1；由 GPIO 位操作产生，保持 delay_us(2)。 |
| IIC 数据（软件模拟） | MPU6050 SDA | **PB7** | 使用专属引脚，不与板载 24C02 共用总线；传感器以 3.3 V 供电。 |
| 电源 3.3 V / 地     | VCC / GND            | 3V3 / GND                                          | 传感器用 3.3 V，可靠共地（4.3″ 屏走板载 LCD 接口，不需单独供电/接线）                                                                      |
| 蜂鸣器              | 板载 BEEP              | 以《探索者开发指南》例程宏为准                                    | **优先复用板载**，少接一个模块                                                                                                |
| 继电器（演示用）         | 继电器模块 IN             | 任一**确认空闲**的 GPIO（如 PA5/PB1，先对照原理图避开被 LCD/模块接口占用的脚） | 模块自带光耦驱动；负载走 5 V/12 V 演示回路，勿直连 220 V                                                                             |
| 按键 | 板载 KEY（KEY0/WK_UP 等） | 以例程为准 | 预留给报警复位或页面切换（EXTI） |
| LED              | 板载 DS0/DS1           | 以例程为准                                              | 运行/状态指示                                                                                                          |
| 4.3″ 触摸屏         | 板载 LCD 接口            | 官方例程已配置（以《开发指南》为准）                                 | 本项目 UI 直接画在这块屏上；驱动/触摸复用官方 LCD 例程，无需自己从零驱动                                                                        |
| 调试/数据口 | 板载 CH340 → PC | USART1（PA9/PA10） | 日志与数据上送；当前配置为 460800 baud。 |
| 12 V 直流风扇        | 独立电源/调速器             | 与逻辑共 GND                                           | 用可调电源或降压模块调速，多档采集                                                                                                |

**要点**：

- 探索者板外设（LCD、模块接口等）占用大量引脚，CubeMX 里**引脚冲突会标红**，接线前先查《探索者开发指南》原理图；
- 通电前：万用表量 3.3 V/5 V 对地无短路；I2C 两线别插反；先跑通官方例程点亮 4.3″ 屏 + 读通 MPU6050，再接蜂鸣器/继电器；
- 演示级报警在调试阶段可先用**板载 LED 闪烁 + 板载蜂鸣器**代替继电器，减少接线出错面。
