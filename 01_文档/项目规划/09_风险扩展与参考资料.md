# 风险、扩展与参考资料


## 1. 当前风险

当前首要风险是正式样本为 0、机械 1× 未独立测速闭环、机械松动无重复性数据、源码/烧录固件/历史日志尚需重对齐。先完成受控松动与不平衡数据质量验证；轴承异常不是扩展范围。


## 2. 风险与预防

| #   | 坑                          | 现象                      | 对策                                                                                                                                                           |
| --- | -------------------------- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | 采样丢点/不等间隔                  | 频谱出现莫名噪声、谱峰变宽           | 用 FIFO+批量读、双缓冲；禁止逐样本阻塞读；上位机检查时间戳                                                                                                                             |
| 2   | 混叠                         | 高频成分折返成假峰               | 采样 1 kHz 时 DLPF 设好（按手册），只看 ≤400 Hz；换宽带宽传感器时同步提采样率                                                                                                            |
| 3   | 频谱泄漏                       | 单频峰拖出长尾巴                | 加 Hann 窗；f0 处用 ±1 bin 邻域峰高而非单 bin                                                                                                                            |
| 4   | 传感器没装牢                     | 特征不稳定、重复性差              | 热熔胶/螺栓刚性固定；固定方式全程不变（相关页面）                                                                                                                                    |
| 5   | 训练与部署特征不一致                 | 离线 95%，板上 60%           | 相关页面 同源纪律；部署前做数值一致性自检（相应步骤）                                                                                                                                |
| 6   | 单一设备过拟合                    | 换台风扇就失效                 | 相关页面 数据矩阵 + 留出设备测试                                                                                                                                           |
| 7   | 类别不平衡                      | 总准确率高但某类召回低             | 看 confusion matrix；均衡采样/加权                                                                                                                                   |
| 8   | 浮点→int8 精度崩                | 概率分布乱                   | 用代表性校准集；量化后重新评估；必要时混用 float 层                                                                                                                                |
| 9   | 屏幕刷新抢占 CPU/总线时间            | 采样丢点、决策抖动               | 屏幕刷新放主循环低优先级；官方并口/FSMC 写屏很快，预留时间片；必要时降低刷新率                                                                                                                   |
| 10  | 中断里做长运算                    | 采样中断被饿死/看门狗复位           | 推理放主循环；中断只做标记与搬运（相关页面）                                                                                                                                       |
| 11  | 供电不足/共地不良                  | 数值漂移、随机复位               | 独立电源共地；继电器感性负载加续流（模块通常已有）                                                                                                                                    |
| 12  | 松动紧固件回退过多                 | 螺母脱落、叶片碰擦或整机跳动       | 从 1/4 圈开始，保留足够螺纹啮合并使用防护罩；出现位移、碰擦或自行旋出立即断电并废弃该段                                                                                                   |
| 13  | 时间失控/烂尾                    | 项目拖成半成品                 | 严格按 相关页面 退出标准推进；跟不上就"砍范围"而不是拖时间                                                                                                                               |
| 14  | 松动实验同时改变了底板固定状态            | 模型学到夹具/桌面差异而非安装松动      | 底板始终用 C 形夹刚性固定；只改变一个编号紧固点；松动前后做恢复基线                                                                                                          |
| 15  | 机械松动等级不可重复                 | 同一标签频谱差异比类别差异还大        | 记录紧固点编号、回退圈数或垫片间隙；至少做 3 轮“基线→松动→恢复”往返验证                                                                                                                                  |
| 16  | 探索者板引脚被板载外设占用              | 外设不工作/CubeMX 标红         | 接线前查《探索者开发指南》原理图；优先复用板载 BEEP/LED/KEY                                                                                                                         |
| 17  | 到货前空等开发板                   | 前两天浪费                   | D1 先学 Python + 下载例程资料（相关页面 选购提示）                                                                                                                             |
| 18  | 4.3″ 屏驱动的引脚/时序配置出错         | 白屏/花屏/不亮                | **直接用官方 LCD 显示例程的工程与驱动**（含初始化与触摸），不要自行从零配屏；到手先跑通官方 LCD 例程                                                                                                    |
| 19  | 风扇小 4pin 接错极性 / PWM 悬空行为不定 | 风扇不转、低速或烧毁              | 上电前用万用表量 4pin 座 12V/GND 极性（黑=GND、红/黄=12V 是电脑风扇惯例，以实物为准）；分线与风扇同为小 4pin 直接对插最稳；PWM 脚（第 4 脚）悬空多数=全速，不转/低速则把 PWM 脚接 +5V 强制全速（或接 GND 取最低速）；本项目电压分档调速、不读转速，测速脚悬空即可 |

> 本表是**事前预防**的通用清单（预计可能踩的坑）。**已经真实发生**过的问题——含报错原文、排查过程、根因与验证结果——统一登记在 **相关页面 开发问题与解决记录**，两条线索互相补充：在 相关页面 看到的坑一旦真的踩了，就去 相关页面 留一条完整记录。

## 3. 参考资料

**芯片与模块手册**

- STM32F407：正点原子探索者资料包（官网下载中心：www.alientek.com）＋ ST 官网产品页/RM0090 参考手册（搜 "RM0090 STM32F407"）
- MPU6050：TDK InvenSense 产品页 https://invensense.tdk.com/products/motion-tracking/6-axis/mpu-6050/ （下载 datasheet & register map，采样率/DLPF 表以它为准）
- SSD1306 OLED：搜索 SSD1306 datasheet / 各家驱动例程

**开发板与教程**

- 正点原子官网（资料/视频下载中心）：http://www.alientek.com/
- 探索者 STM32F407ZGT6 板卡信息参考：https://t.elecfans.com/product/65
- RT-Thread 对探索者 F407 的 BSP（可作引脚/工程参考）：https://github.com/RT-Thread/rt-thread/tree/master/bsp/stm32/stm32f407-atk-explorer

**算法与工具**

- CMSIS-DSP（FFT 等函数）：https://arm-software.github.io/CMSIS-DSP/latest/
- ST X-CUBE-AI（模型转换与验证工具）：https://www.st.com/en/embedded-software/x-cube-ai.html
- X-CUBE-AI + CubeMX 在 STM32F407 部署的中文实操教程：https://blog.csdn.net/weixin_63113550/article/details/145967973
- TensorFlow Lite Micro：https://github.com/tensorflow/tflite-micro
- Edge Impulse（可参考其"运动/振动分类"公开教程思路）：https://docs.edgeimpulse.com/

**学习资料**

- 正点原子《探索者 STM32F407 开发指南》（HAL 版例程，与你学的视频同源）
- 振动状态监测入门：ISO 10816 概述（机械振动评价标准，了解即可）
- 《TinyML》/ ST 官方 TinyML 网络课程（可选）
