# 技术原理与设计边界


## 1. 当前适用范围

项目仅覆盖低转速小风扇的正常、不平衡与安装固定处机械松动；轴承异常相关内容是历史方案。当前链路固定 X 为振动测量轴、Y 为重力轴。1 kHz、1024 点、Hann 和 10～400 Hz 是当前配置，但机械 1× 仍须以 TACH 或变电压谱线跟踪完成实测闭环。


## 2. 振动故障机理

### 2.1 故障机理

旋转机械的机械故障会以**特征频率**的形式体现在壳体振动信号里：

| 故障        | 物理机理           | 典型频域特征                                             | 用 MPU6050(1 kHz/带宽~400 Hz) 可观测性                              |
| --------- | -------------- | -------------------------------------------------- | ------------------------------------------------------------ |
| 转子不平衡     | 质量偏心 → 旋转离心力   | **1× 转速频率**处出现显著谱峰，且幅值随转速平方增大                      | ✅ 最容易复现、特征最清晰（首选故障）                                          |
| 地脚松动/结构松动 | 连接刚度下降、非线性     | 1× 幅值增大并伴随 2×、3×…高次谐波、0.5× 等                       | 🟡 可人为"拧松螺丝"模拟，特征可辨                                          |
| 不对中       | 轴线不共线          | 以 **2× 转速**为主，伴 1×、高次                              | 🟡 在家较难规范模拟，可后补                                              |
| 转子碰摩/异物   | 转静件接触          | 宽带噪声 + 谐波激增                                        | 🟡 可用杂物轻触模拟，注意安全                                             |

> 结论：对本项目低转速直流风扇，**不平衡重点看 1×；安装松动重点看 1× 幅值变化、2×/3× 等谐波丰富度及可能出现的 0.5×**。最终是否可分必须由同一夹具上的往返重复实验确认。

### 2.2 采用频域分析的原因

- 原始时域波形受安装噪声、重力分量、低频漂移干扰大，肉眼和模型都难直接区分；
- 频域把能量按频率分开：25 Hz 风扇的"不平衡"就是 25 Hz 一根峰，特征**物理含义明确、可解释**；
- 频率分辨率：Δf = fs / N = 1000 / 1024 ≈ **0.98 Hz**，足够定位基频；
- 本项目 12 V 小风扇（已购：6 cm，2300–3500 rpm）→ 1× 基频约 **38–58 Hz**（2× 约 77–117 Hz），均在分析带宽内、谱峰明显；示例里常提的 25 Hz 只是家用风扇转速，作概念说明用；
- 谱特征比原始波形对"传感器摆放细微差异"更鲁棒，小数据集也训得动。

### 2.3 加窗与谱估计

- 直接对 1024 点截断做 DFT 会**频谱泄漏**（旁瓣）；工程上先乘**汉宁窗（Hann）**再 FFT；
- 用幅度谱的对数或分段能量作为特征，比用复数谱稳定；
- 转速基频 f0 的估计：找低频段（如 5–60 Hz）谱峰，或直接用设定转速换算（进阶：自动基频估计 + 特征按 f0 归一化，抵御转速漂移）；
- 特征建议做成**相对量**（如 A(1×)/总能量、高频段能量占比），降低传感器安装一致性带来的绝对值差异。

### 2.4 传感器带宽边界

- MPU6050 内部 DLPF 可配，加速度通道标准配置下有效带宽有限（常用配置 ~260 Hz 及以下，具体以**数据手册**为准；ODR 最高可配 1 kHz 量级）；
- 因此本系统**分析上限按 ~400 Hz 规划（1 kHz 采样、Nyquist 500 Hz 的安全余量）**，适合本项目的低阶转频、谐波和低频结构响应，不宣称覆盖高频冲击型故障；
- 对策（任选其一，写入答辩口径）：
  1. 面向对象限定为**低转速小型风扇/电机**（本系统设计域），把话说准确；
  2. 若将来迁移到高转速或高频冲击场景，再换宽带宽加速度计（如 IIS3DWB、或模拟输出传感器 + ADC）并重新采集定义对应类别；当前项目不扩展轴承异常。
- 其他采样工程点：采样要用 **FIFO + 中断/轮询批量读**而不是逐样本读（保证等间隔）；避免把 FFT 窗口取得太短（转速越低，需要的窗口越长才够分辨率）。
