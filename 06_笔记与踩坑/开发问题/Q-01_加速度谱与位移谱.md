# 加速度谱与位移谱


## 1. 当前结论

轴承磨损讨论是历史分析，Q-05 已永久替换该类别。当前仍使用加速度谱作为主分析量；若评估速度 RMS，须以正式 v3 数据和设备留出测试重新裁决。


## 2. 问题概述

加速度谱 vs 二次积分位移谱，哪个更能区分"正常 / 不平衡 / 轴承磨损"？

> **类型**：设计选择题（不是报错），发生在 D5–D6 采数之前的特征设计阶段。

### 2.1 编号 / 标题

Q-01 — MPU6050 原始加速度做 FFT，与"加速度二次积分后再 FFT"（位移谱）相比，哪个更能反映风扇的三种状态？

### 2.2 时间 / 阶段

2026-09-11；D0（到货前设计期），尚未开始实测采数。

### 2.3 现象（原始疑问）



> "MPU6050 传感器测量出的加速度使用 FFT 进行处理后的数据，和加速度二次积分后再进行 FFT 处理的数据对比，哪个更能反映风扇正常 / 不平衡 / 轴承磨损三种状态？"

### 2.4 排查过程（分析链）



1. **认清积分在频域干了什么**：积分 = 频谱每个频率乘一次 1/(2πf)，所以一次积分（→速度）低频抬起，**二次积分（→位移）高频乘 1/f² 被压低、低频被放大**。即二者不是"信息多少"的差别，而是**频率加权**不同（换一副眼镜）。
2. **比对三类状态的证据分布**（对照 相关页面 机理表、相关页面 特征）：
   - 正常：整体幅值低、无 1× 显著峰 → 两者都看得到；
   - 不平衡：证据是 **1× 转速峰（38–58 Hz）** → 加速度谱已足够（相关页面 特征 2）；位移谱也看得到，但无净收益；
   - 轴承磨损：证据是 **200–400 Hz 宽带能量上升 + 峭度/峰值因子**（相关页面 表、相关页面 特征 6/8/9）→ 只在加速度谱里明显，**位移谱把它压得几乎看不见**。
3. **估算零偏漂移量级**（MEMS 零偏必然非 0，时域累积积分的误差按 t² 增长）：
   - 假设残余零偏仅 0.01 g ≈ 0.098 m/s² → 1 s 内位移漂移 ≈ ½×0.098×1² ≈ **0.049 m = 49 mm**；
   - 而 45 Hz、0.05 g 的真实振动位移幅值 X = a/ω² = 0.49/(2π×45)² ≈ **6.1 µm**；
   - 两者相差约 **8000 倍** → 1 s 窗口里二次积分结果基本被漂移与低频噪声淹没。
4. **对照行业做法**：ISO 10816 一类评价里，**低转速机组才用位移**（加速度幅值 ∝ ω²，转速一低 1× 就埋进本底噪声），中高转速普遍用**速度 RMS（约 10–1000 Hz 限带）**。本项目风扇 2300–3500 rpm = 38–58 Hz，**不属于低速区**。

### 2.5 根本原因



- 加速度↔位移的换算在频域是 1/(2πf)² 的**加权**，不是补充新信息；二次积分天然压制高频（= 压制轴承磨损的证据）；
- 时域累积积分会把直流零偏、温漂按 t² 放大，而 MEMS 零偏不可能为 0，长窗口必然发散。

### 2.6 解决方法（结论与操作规则）



1. **主特征继续用加速度谱**（相关页面 的 12 维不动），轴承磨损靠高频段能量占比 + 峭度 + 峰值因子捕捉；
2. 若想补一维跨界可比的特征，**用一次积分的"速度 RMS（限带 10–400 Hz）"**，比二次积分稳健得多（也是工业界常用量）；
3. 若确实要做位移谱，四条纪律缺一不可：①先减均值 / 高通 5–10 Hz 去直流与重力；②**用频域积分**（谱 ÷ jω，两次 ÷(jω)²），不要用时域梯形累积；③**把 0 Hz 及近 0 Hz 的 bin 置零**（否则除以 ω² 发散）；④限带（10–400 Hz）内比较，且**只当相对特征**，不得拿绝对值对标 ISO 限值（未做绝对校准）；
4. **用实验裁决**：同一批数据算"加速度谱 / 位移谱"两组特征 → 同一分类器 → 同一批留出风扇 → 比混淆矩阵中 **bearing_wear 那一行的召回率**。

### 2.8 经验与可复用点



- **口诀**："先看证据落在哪个频段，再决定给频谱戴哪副眼镜——积分是低频放大镜，微分是高频放大镜。"
- **通用教训**：任何对 MEMS 数据做积分的场合，先处理零偏、再评估 t² 漂移量级；能一次积分就别二次积分。
- **面试话术**："位移谱和加速度谱不是信息多少的区别，而是频率加权（1/f²）：二次积分放大低频漂移、压制高频冲击，而轴承类故障的证据恰恰在高频宽带，所以本项目用加速度谱，并靠峭度与高频段能量占比捕捉磨损。"
